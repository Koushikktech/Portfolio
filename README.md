# Portfolio — Krishna Koushik Kasarla

Personal portfolio and interaction lab built with Next.js 16, React 19, Three.js, and Framer Motion.

## Features
- **3D Optical Glass Hero**: Real-time fluid harmonic vertex displacement mesh with crystal transmission glass and reactive mouse lensing.
- **Craft Showcase**: Curated systems, AI automation, and interactive web architecture projects.
- **Lab**: Minimal retro-cyber arcade breakout mini-game with high score tracking.
- **Retro Cyber Boot Screen**: Batched Canvas 2D serpentine matrix sequence.
- **Zero-Latency Custom Cursor**: Touch-safe adaptive cursor with spring physics.

## Tech Stack
- Next.js 16 (Turbopack) & React 19
- Three.js & React Three Fiber / Drei
- Framer Motion
- Tailwind CSS

## Getting Started

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
